这是一个**医院预约管理系统**，采用前后端分离架构，包含三个角色：

### 技术栈

| 层级    | 技术                                          |
| :------ | :-------------------------------------------- |
| 前端    | Vue 3 + Vite + Element Plus + Pinia + ECharts |
| 后端    | Spring Boot 2.7 + MyBatis + MySQL + Redis     |
| 认证    | Sa-Token                                      |
| API文档 | Knife4j / Swagger                             |

### 项目结构

```
  hos/            # 前端 (Vue 3 SPA)
  hos-project/    # 后端 (Spring Boot + Maven 多模块)
  backup.sql      # 数据库备份
```

后端三个模块：

- **hos-server** — 控制器、服务、拦截器、配置
- **hos-pojo** — 实体类、DTO、VO
- **hos-common** — 通用常量、异常、工具类

### 三个角色功能

1. **管理员** — 管理医生/科室/专业，查看数据统计，导出报表
2. **医生** — 查看预约列表，处理/完成预约
3. **用户/患者** — 注册登录，浏览医生并预约，管理预约记录和病历

### 核心业务

- 用户选择医生和时间段创建预约，预约状态：待处理(0) / 已完成(1) / 已过期(3)
- 定时任务每天 17:00 将超时的待处理预约标记为过期
- Redis 缓存医生查询，阿里云 OSS 存储医生头像
